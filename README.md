# Praticas do estudo sobre Java

As pastas estão separadas por capítulo das aulas sobre o java. Cada capítulo tinha pelo menos um desafio.
Com as aulas consegui relembrar a sintaxe do java, como funciona as estruturas condificionais dele, e de repetição, como desenvolver metodos, funções, tipos de variáveis que ele tem e como desenvolver um software simples com java.
